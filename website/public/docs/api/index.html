API Reference

Magec exposes two separate HTTP servers, each with its own Swagger UI where you can explore every endpoint, see request/response schemas, and try things out directly from the browser.

User API — :8080

This is the API that clients use to talk to agents. The Voice UI, Telegram, webhooks, and any external integration goes through here.

Swagger UI → http://localhost:8080/swagger/

All endpoints require a client token: Authorization: Bearer mgc_...

What you’ll find:

  • Agent runtime — Send messages to agents (/agent/run for blocking, /agent/run_sse for streaming). These follow the Google ADK protocol.
  • Sessions — Create, list, get, update, and delete conversation sessions. Each session holds the full message history for a user-agent pair.
  • Artifacts — Files and data generated by agents during a session. Versioned, so you can retrieve any past version.
  • Voice — Speech-to-text and text-to-speech proxies for agents that have STT/TTS configured. Plus a WebSocket endpoint for real-time wake word and VAD events.
  • Webhooks — Trigger endpoint for webhook clients.
  • Debug — Execution traces and event graphs for debugging agent behavior.

Quick example

curl -X POST http://localhost:8080/api/v1/agent/run \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer mgc_your_client_token" \
  -d '{
    "app_name": "AGENT_ID",
    "user_id": "user1",
    "session_id": "session1",
    "new_message": {
      "role": "user",
      "parts": [{ "text": "Hello!" }]
    }
  }'

Admin API — :8081

This is the management API that powers the Admin UI. Full CRUD for every resource type in the platform.

Swagger UI → http://localhost:8081/swagger/

No authentication required (bind it to localhost or a private network in production).

Resource What you can do
Agents Create, update, delete. Configure LLM, memory, voice, MCP tools per agent.
Flows Create and edit multi-agent workflows with sequential, parallel, and loop steps.
Backends Manage AI provider connections (OpenAI, Anthropic, Gemini, Ollama, etc.).
Memory Configure session (Redis) and long-term (PostgreSQL/pgvector) memory providers. Health check included.
MCP Servers Add external tools via HTTP or Stdio transport.
Commands Define reusable prompts for cron jobs and webhooks.
Clients Manage Direct, Telegram, Webhook, and Cron clients. Token regeneration.
Both Swagger UIs are interactive — you can execute requests directly from the browser to test endpoints without writing any code.
